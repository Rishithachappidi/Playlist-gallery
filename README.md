#  Playlist Gallery

A simple web-based playlist gallery built with **HTML, CSS, and JavaScript**.

##  About

Playlist Gallery is a frontend project created to explore and practice the fundamentals of web development. It presents music playlists through a simple interactive interface.

##  Technologies Used

- **HTML5** — Structure of the webpage
- **CSS3** — Styling and layout
- **JavaScript** — Interactivity and functionality

## 🎯 Project Purpose

This project was developed to practice:

- Creating webpages with HTML
- Styling interfaces with CSS
- Adding interactivity using JavaScript
- Organizing a basic frontend project
