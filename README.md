# Playlist Gallery

A modern, responsive music discovery interface built with **HTML, CSS, and JavaScript**.

Playlist Gallery is designed as a personal music space where users can explore songs, search across the catalogue, like tracks, build a personal playlist, and view listening statistics through a clean dark-themed interface.

##  Live Demo

**[Open Playlist Gallery](https://rishithachappidi.github.io/Playlist-gallery/)**

## Features

-  32-track music catalogue
-  Music across 6 languages
-  Search songs, artists, and albums
-  Like and unlike songs
-  Build a personal playlist
-  Play/pause interface
-  Previous and next track controls
-  Shuffle mode
-  Repeat mode
-  Progress and volume controls
-  Listening statistics
-  Recently played section
-  Persistent data using LocalStorage
-  Keyboard shortcuts
-  Responsive layout for different screen sizes
-  Premium dark-themed interface

> **Note:** The current version focuses on the interface and music-management experience. It does not include real audio playback or bundled music files.

##  Technologies Used

- **HTML5** — Page structure and semantic content
- **CSS3** — Responsive layout, styling, animations, and visual design
- **JavaScript** — Application logic, navigation, search, playlists, favourites, player controls, and LocalStorage

## 🚀 Run Locally

No framework or build tool is required.

1. Clone the repository:

```bash
git clone https://github.com/Rishithachappidi/Playlist-gallery.git
```

2. Open the project folder:

```bash
cd Playlist-gallery
```

3. Open `index.html` in your browser.

That's it — the project runs directly in the browser.

## Data Persistence

Playlist Gallery uses the browser's **LocalStorage** to preserve user-side data such as:

- Liked songs
- Personal playlist
- Recently played tracks
- Listening statistics
- Volume preferences

This means the data is stored locally in the user's browser rather than on a remote server.
